# Go를 공부하는 엄숙한 공간 입니다.

이곳은 Go를 공부 하기 위한 프라이빗하고
**아주아주아주아주 엄숙한 공간**입니다.

# 이유

채소 가게에 일하게 됐는데 그녀석들이 Go를 쓰고 있어서 공부해야 합니다.

회사 몰래 합니다. 하다가 어지러우면 그녀석을 흔들 수 도 있습니다.(발견 즉시 살려주세요)

# 목표

```
문법 / 타입 / 슬라이스 / 맵
      ↓
구조체 / 메서드 / 인터페이스
      ↓
에러 처리 (error, wrapping, panic)
      ↓
고루틴 / 채널 / sync
      ↓
context — 취소 / 타임아웃
      ↓
표준 라이브러리 (net/http, encoding/json, io)
      ↓
테스트 (testing, table-driven, 벤치마크)
      ↓
모듈 / 패키지 구조 / 빌드 / 배포
      ↓
gRPC — 결국 그녀석이 쓰고 있는 것
```
